## ✨ Why this project feels great

- 🎨 **Modern glassmorphism UI** with gradient visuals and polished cards  
- 📊 **Beautiful analytics** with category and 7-day trend charts  
- 🔐 **Simple login experience** (demo mode) for per-user local data  
- ⚡ **Fast and lightweight** — no backend needed  
- 💾 **Persistent storage** with `localStorage` per email

---

## 🧭 App experience

1. **Login / Signup** with any email + password (demo mode).
2. **Track transactions** as Income or Expense.
3. **See live stats** for balance, totals, and transaction count.
4. **Explore charts** for category spending and weekly trend.
5. **Manage entries** by deleting transactions anytime.

## 🚀 Quick Start

Since this is a single-page app, no install is required.

1. Clone this repository.
2. Open this file in your browser:
   - `/home/runner/work/Expense-Calculator/Expense-Calculator/index.html`

Or host it quickly with any static server.
